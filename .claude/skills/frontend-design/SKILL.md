此技能指导创建独具风格、达到生产级质量的前端界面，避免「AI 流水线」风格的审美。实现真实可用的代码，对美学细节和创意选择倾注超乎寻常的专注。

用户提供前端需求：要构建的组件、页面、应用或界面。可能包含关于目的、受众或技术约束的上下文。

## 设计思维

编码之前，先理解上下文并确定一个**大胆的美学方向**：

- **目的**：这个界面解决什么问题？谁会使用它？
- **风格基调**：选择一个极端：极致的极简主义、极繁主义的混沌、复古未来主义、有机/自然、奢华/精致、俏皮/玩具感、编辑/杂志风、粗野主义/原始、装饰艺术/几何、柔和/粉彩、工业/实用主义等等。有无数种风格可供选择。以上作为灵感参考，但最终要设计出忠实于所选美学方向的独特风格。
- **约束条件**：技术限制（框架、性能、无障碍访问）。
- **差异化**：是什么让它**令人过目不忘**？人们会记住的**那一个点**是什么？

**关键**：选择一个清晰的概念方向，并用精度将其贯彻到底。大胆的极繁主义和精炼的极简主义都行得通——关键在于**意图明确**，而非强度。

然后实现真实可用的代码（HTML/CSS/JS、React、Vue 等），做到：
- 达到生产级质量，功能完整
- 视觉震撼，令人难忘
- 具有清晰美学观点的高度一致性
- 每个细节都精心打磨

## 前端美学指南

重点关注：

- **排版**：选择优美、独特、有趣的字体。避免使用 Arial、Inter 等通用字体；选择能提升前端美感的独特字型；出人意料、富有个性的字体搭配。将一款独特的展示字体与一款精致的正文字体配对使用。
- **色彩与主题**：坚持统一的美学风格。使用 CSS 变量保持一致性。主导色配锐利点缀色的效果远胜于畏首畏尾、平均分配的调色板。
- **动效**：使用动画来实现效果和微交互。HTML 场景优先使用纯 CSS 方案。React 场景使用 Motion 库（如果可用）。聚焦高光时刻：一次精心编排的页面加载动画配合逐次展现（animation-delay）带来的愉悦感远胜于零散的微交互。使用滚动触发和令人惊喜的悬停状态。
- **空间构成**：打破常规的布局。不对称。重叠。对角线流动。打破网格的元素。宽裕的负空间**或**有节制的密度。
- **背景与视觉细节**：营造氛围感和层次感，而非直接使用纯色。添加与整体美学匹配的情境化效果和纹理。运用创意形式，如渐变网格、噪点纹理、几何图案、叠层透明度、戏剧性阴影、装饰性边框、自定义光标以及颗粒叠加。

**绝对不要**使用千篇一律的 AI 风格，例如烂大街的字体族（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（尤其是白色背景上的紫色渐变）、毫无惊喜的布局和组件模式、缺乏上下文特色的模板化设计。

以创意的角度解读需求，做出令人意外且真正为上下文量身定制的选择。每个设计都应当独一无二。在亮色主题与暗色主题、不同字体、不同美学之间交替变化。**绝不要**在多次生成中趋同于某些常见选择（例如 Space Grotesk）。

**重要**：实现复杂度要与美学愿景匹配。极繁主义设计需要华丽的代码，包含丰富的动画和效果。极简或精炼的设计则需要克制、精准，以及对间距、排版和微妙细节的精益求精。优雅来自于将愿景执行到位。
